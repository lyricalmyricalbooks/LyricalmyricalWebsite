## Review

The SDK sends nothing while Claude is paused, so an empty balance can never turn into a bill; Anthropic itself refuses
requests without credits. Live calls were not made (no key in this environment): out-of-credits detection is tested
against Anthropic's documented error shapes. Server-side refusal fallbacks are left off on purpose to keep cost predictable.
